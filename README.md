# Spotify_Music_Analytics_2015-2025
Spotify Music Analysis Dashboard (2015–2025) An interactive data analysis dashboard built with HTML, CSS, and Chart.js, exploring 85,000 Spotify tracks across 10 countries and 12 genres from 2015 to 2025.

Features 8 analysis tabs:

🔥 Popularity — what factors drive song popularity

🎵 Genre — which genres dominate streaming

🌍 Country — music preferences by country

▶ Streams — what makes a hit song

⚠ Explicit — does explicit content perform better

🎤 Artists — top performers by streams and popularity

🏢 Labels — which record labels lead the industry

📈 Trends — how music has evolved from 2015 to 2025
